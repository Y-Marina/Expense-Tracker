#Expense Tracker!
## Отслеживайте свои доходы и расходы

Приложение для отслеживания своего дохода. Позволяет добавлять доход(income) и расход(expense). Сортируйте свой заработок по категориям, а позже смотрите его на графике!

## стек:
Kotlin
Jetpack Compose
MVVM Architecture
Room Database
Dagger Hilt
Navigation Compose
